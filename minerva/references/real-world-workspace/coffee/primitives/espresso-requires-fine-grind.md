# Espresso —[requires]→ Fine Grind

Эспрессо требует мелкого помола для создания достаточного сопротивления потоку воды под давлением.

- **Субъект:** Espresso
- **Предикат:** requires
- **Объект:** Fine Grind
- **Обоснование:** крупный помол не создаёт сопротивления → вода проходит слишком быстро → недоэкстракция

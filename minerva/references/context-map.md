# Context Map — легенда связей

**Первичная карта контекстов:** `references/index.md`

Этот файл — детализация типов связей между контекстами (ADR-008). Используется когда нужно уточнить характер отношения, а не просто список контекстов.

## Типы отношений (DDD Context Mapping)

| Тип | Описание | Когда использовать |
|---|---|---|
| **Partnership** | Две команды координируют изменения | Контексты развиваются синхронно |
| **Shared Kernel** | Общая часть модели используется обоими | Общие Primitives между контекстами |
| **Customer–Supplier** | Upstream определяет, downstream подчиняется | Зависимость одного контекста от другого |
| **Conformist** | Downstream принимает модель upstream без переговоров | Жёсткая интеграция без возможности влиять |
| **Anti-Corruption Layer** | Изолирующий слой между разными моделями | Интеграция разных таксономий |
| **Open Host Service** | Протокол доступа определён и стабилен | Публичный API / query layer |
| **Published Language** | Общий язык для обмена данными | Стандартизированные форматы обмена |
| **Separate Ways** | Контексты независимы, интеграция не нужна | По умолчанию для несвязанных контекстов |

## Текущие связи

На данный момент все контексты — **Separate Ways** (независимы). Связи появятся при росте workspace.

## Формат записи

```yaml
coffee --[Customer-Supplier]--> equipment
# coffee зависит от equipment, но не наоборот
```

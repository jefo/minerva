## §0 Engineering Intent → Strategy → Consequences

### Layer 1 — Intent (одно предложение)

> Создать 24C/32T (8P+16E) Raptor Lake Refresh CPU на единой кольцевой шине, максимизируя однопоточную частоту и latency-sensitive многозадачность при ограничении 253W PL2 и финальном поколении LGA1700.

### Layer 2 — Strategy (список инженерных решений)

- **S1:** Разместить 8 P-cores (Raptor Cove) + 16 E-cores (Gracemont) на единой кольцевой шине с общим 36 MB L3 — монолитная архитектура, не чиплет
- **S2:** Достичь 6.0 GHz TVB на 1–2 P-cores при 253W PL2 — частотный рекорд без IF-latency penalty
- **S3:** Сохранить dual-channel DDR5-5600 / DDR4-3200 и платформу LGA1700 — зрелая экосистема, низкая цена плат
- **S4:** Использовать Intel Thread Director для распределения 32 потоков между P/E-ядрами — asymmetric scheduling

### Layer 3 — Consequences (список следствий)

- **C1:** Однопоточная производительность — максимум среди consumer CPU (6.0 GHz + Raptor Cove IPC)
- **C2:** Межъядерная latency минимальна (кольцо), без NUMA-штрафа двух CCD
- **C3:** Стриминг + игра без потери FPS: E-cores берут OBS/Discord/browser, P-cores — игру
- **C4:** ALL-core sustained 5.6 GHz при 253W требует 360mm AIO — SFF и тихие сборки исключены
- **C5:** LGA1700 — финальное поколение без upgrade path на будущие архитектуры

## §1.5 Tradeoff Table

Каждая строка — развёртка L2-решения на глубину: каким ресурсом распорядились, что решили и почему.

| # | Ресурс (resource) | Решение (decision) | Обоснование (why) | Маркер |
|---|-------------------|--------------------|--------------------|--------|
| **T1** | **Silicon topology / inter-core fabric** | Монолитная кольцевая шина с единым 36 MB L3 для всех 24 ядер — вместо чиплетной компоновки (как у конкурентов с двумя CCD) | Минимальная межъядерная latency: любое ядро достигает любого другого за один такт кольца. Единый LLC-домен без NUMA-штрафа: 36 MB L3 видны всем ядрам без cross-CCD трафика. Платят площадью кристалла: монолит 257 mm², весь кэш и ядра на одном кристалле — дороже чиплетов, но даёт детерминированную latency. | `[fact]` — 36 MB L3, кольцевая шина из спецификаций Raptor Lake; `[inference]` — latency-преимущество монолита над двумя CCD выводится из топологии |
| **T2** | **Frequency headroom / power budget** | 6.0 GHz TVB на 1–2 P-cores в конверте 253W PL2, каскад бустов: 5.8 GHz TBM3, 5.6 GHz all-core | Intel 7 (10nm Enhanced SuperFin) на финальной итерации даёт максимальный разгонный потенциал поколения. TVB активируется только при достаточном термальном запасе (температура < 70°C) — 6.0 GHz достижим на single-core нагрузках с мощным охлаждением. 253W PL2 — плата за частоту: без этого конверта sustained 5.6 GHz all-core невозможен. | `[fact]` — 6.0 GHz TVB, 5.8 GHz TBM3, 5.6 GHz Max Turbo из спецификаций; `[inference]` — связь TVB-условий (температура < 70°C) и охлаждения |
| **T3** | **Platform / memory controller** | LGA1700 + dual-channel DDR5-5600 (обратная совместимость с DDR4-3200) — финальное поколение сокета | LGA1700 — третий год на рынке: сотни моделей плат от $100 до $1000, зрелые BIOS, отлаженные профили памяти. DDR4-совместимость — мост для пользователей с существующим парком памяти. Платят отсутствием upgrade path: LGA1700 не получит будущих архитектур. | `[fact]` — DDR5-5600 / DDR4-3200, LGA1700 из спецификаций; `[inference]` — зрелость экосистемы как tradeoff против отсутствия апгрейда |
| **T4** | **Thread scheduling / OS integration** | Аппаратный Intel Thread Director (в кристалле) + программная поддержка Windows 11 ≥ 22H2 — вместо симметричного планировщика ОС | Асимметричные ядра (P vs E) без аппаратного планировщика — лотерея: latency-sensitive поток на E-core даёт падение ×2–3. Thread Director мониторит IPC, тепловыделение и тип инструкций каждого потока в реальном времени, назначая P-cores для latency-critical, E-cores для throughput. Платят зависимостью от ОС: старые Windows / Linux без Thread Director теряют эффективность гибридной архитектуры. | `[fact]` — Intel Thread Director, требование Windows 11 ≥ 22H2 из документации; `[inference]` — падение ×2–3 на E-core для latency-sensitive потоков из профилей KB |

### Prose-мост: от компромиссов к продукту

**Вопрос: какой продукт получается в результате этих компромиссов?**

**Ответ:** Core i9-14900K — это инженерный ответ на вопрос «как выжать максимум однопоточной частоты и latency-sensitive многозадачности из зрелой платформы на финальном поколении сокета». Intel взяла форсированный кристалл Raptor Lake Refresh на Intel 7, разогнала P-cores до 6.0 GHz (частотный рекорд потребительского сегмента), сохранила монолитную кольцевую шину для минимальной межъядерной задержки и доверила распределение 32 потоков аппаратному Thread Director. Результат — CPU, который в стриминге + игре не теряет FPS (E-cores разгружают P-cores), в однопотоке быстрее любого consumer-конкурента, но требует 360mm AIO и исключает SFF-сборки. Платформа LGA1700 — зрелая и дешёвая, но без upgrade path.

### 10.2 ENTAILS Edge Justification

| Ребро | Класс | Обоснование (развёрнутое) |
|-------|-------|--------------------------|
| **N1 → N5** | **ENTAILS** | Thread Director — аппаратный планировщик, различающий P-cores и E-cores по IPC, тепловыделению и типу инструкций. Без понимания что такое P-core (latency-optimised, HT) и E-core (throughput-optimised, без HT) читатель не может осмыслить *зачем* нужен планировщик и *что именно* он планирует. Если читатель не знает о существовании двух типов ядер, Thread Director — абстрактный механизм без назначения. Контрольный вопрос: «Можно ли объяснить человеку, как работает сортировщик багажа, если он не знает что багаж бывает ручной кладью и чемоданом?» → Нет. |
| **N3 → N7** | **ENTAILS** | Competitive positioning 14900K держится на утверждении «однопоточная производительность — максимум среди consumer CPU». Это утверждение целиком опирается на частотный стек: 6.0 GHz TVB, 5.8 GHz TBM3, 5.6 GHz all-core. Без понимания того, что TVB активируется только на 1–2 ядрах при термальном запасе < 70°C, читатель не может оценить *условия*, при которых достигается этот максимум. Контрольный вопрос: «Можно ли понять почему 14900K — single-thread champion, не зная что он достигает 6.0 GHz, как это работает и при каких условиях?» → Нет. Цифра 6.0 GHz без контекста TVB — пустой маркетинговый claim; с контекстом N3 — инженерный факт. |

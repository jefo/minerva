# RME Fireface UFX II

## Позиционирование
Флагман RME. 30 in/out, 4 преампа SteadyClock FS, MADI, аппаратные DSP-эффекты. Профессиональная студия.

## Характеристики
| Параметр | Значение |
|---|---|
| Driver Tier | T0_Reference |
| Входы/Выходы | 30 / 30 |
| Преампы | 4 (+48V) |
| Цифровые I/O | 2x ADAT + MADI |
| DSP | Dynamics, EQ, Reverb, Delay |
| RTT @ 64 | ~2.0 ms |
| Форм-фактор | 1U Rack |

## Для кого
- Профессиональная студия (30+ каналов)
- Запись концертов (MADI)

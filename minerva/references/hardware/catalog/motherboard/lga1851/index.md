# LGA1851 — материнские платы

Сокет LGA1851 для процессоров Intel Core Ultra 200 (Arrow Lake). Пришёл на смену LGA1700.

## Чипсеты LGA1851

| Чипсет | Разгон CPU | PCIe 5.0 GPU | PCIe 5.0 M.2 | DDR5 | Позиционирование |
|---|---|---|---|---|---|
| **Z890** | Да | Да | Да | Да | Флагман |
| **B860** | Нет | Да (x16 CPU) | Да (1 порт) | Да | Средний сегмент |
| **H810** | Нет | Нет | Нет | Да | Бюджет |

> LGA1851 — новый долгоживущий сокет Intel (как минимум 2 поколения CPU). В отличие от LGA1700, **DDR4 не поддерживается** — только DDR5.

### Что ещё нужно заполнить

- Z890: MSI Tomahawk, Gigabyte Aorus Elite, ASUS Strix
- B860: среднебюджетные платы (ожидаются в Q3-Q4 2025)
- Mini-ITX платы на Z890/B860

## Что смотреть при выборе LGA1851-платы

1. **VRM-фазы и охлаждение** — Arrow Lake потребляет до 250W в турбо, требуется качественная подсистема питания (см. `../../concepts/vrm-phases.md`)
2. **PCIe 5.0** — все Z890-платы имеют PCIe 5.0 x16 от CPU; B860 может урезать
3. **DDR5-6400 — sweet spot** для Arrow Lake (Gear 2)
4. **Flashback без CPU** — критично для обновления BIOS под будущие поколения CPU на LGA1851

## Ключевые параметры

- **Тип матрицы** — OLED (мгновенный отклик, риск выгорания) vs IPS (без выгорания, glow)
- **FreeSync / G-Sync** — совместимость с GPU
- **HDR** — DisplayHDR 400 (бесполезен) → 600 → 1000 (настоящий HDR)

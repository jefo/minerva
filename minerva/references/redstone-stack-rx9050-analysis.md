# Redstone Stack on RX 9050 — Behavioral Analysis

**Target GPU:** AMD Radeon RX 9050 (RDNA 4, Navi 44, 16 CU, 8GB GDDR6 128-bit)
**Source data:** RX 9070 / 9070 XT (64 CU, тот же 2nd Gen AI Accelerator блок)
**Caveat:** Абсолютные цифры не масштабируются линейно вниз. Качественный характер поведения технологии переносится.
**Date:** 2026-07-29

---

## Что Redstone делает на RX 9050 (а не на флагмане)

Redstone не превращает 1080p Medium/Balanced в ультра-карту, но делает три вещи:

1. **Поднимает FPS** без сильного мыла в движении
2. **Позволяет включать RT/патчтрейс** там, где чистый растр без FG был бы неиграбельным
3. **Делает картинку чище и стабильнее по кадрам** (меньше TAA-смазов, лучший шейдинг/отражения), но ценой чуть худших 1% lows и небольшого роста задержки

---

## Компоненты стека

| Компонент | Механика | Требования |
|-----------|----------|------------|
| **ML-апскейл (FSR Redstone)** | Рендер на пониженном разрешении → ML-модель дорисовывает до натива | DX12 + Agility SDK 1.4.9+, RDNA4 exclusive |
| **ML Frame Generation** | Вставка AI-кадров между отрендеренными | DX12, RDNA4 only |
| **Ray Regeneration** | ML-деноизер для RT/патчтрейсинга — берёт шумный выход от малого числа лучей → чистая картинка | Игра должна поддерживать RR |
| **Radiance Caching** | Кэширование освещения для экономии лучей | Пока мало игр, 2026+ |

Важно: Redstone — это набор; в конкретной игре могут быть включены не все компоненты.

## Сценарии использования

### 1. Комфортный 1080p (онлайн-шутеры, кооп, инди)

**Включаем:** ML-апскейл (Quality) + FG. RR не нужен (нет RT).

**Результат:**
- AVG FPS в районе 60–90+ (зависит от игры), очень плавная картинка
- 1% lows лучше чем без FG, но чуть хуже чем с FSR3 FG (ML-генерация тяжелее)
- Задержка чуть выше чем без FG. Для PvE/коопа — не критично. Для кибера — тестировать, возможно играть без FG

**Выигрыш:** плавность и ощущение 90+ Гц без покупки RTX 5060/B580.

### 2. AAA с RT (Cyberpunk, Avatar, Witcher 4 — когда добавят поддержку)

**Включаем:** RT On (Medium/High) + RR + ML-апскейл + FG.

**Результат:**
- RT без шума и зернистости (RR чистит картинку)
- FG компенсирует потери от RT, выравнивая FPS
- При Path Tracing + RR + FG — RX 9050 сможет потянуть в 1080p, но: High/RT-On, не Path Tracing на ультра с максимальными сэмплами
- 8GB VRAM — лимитирующий фактор, даже если шейдинг вытягивается

### 3. 1080p на 144 Гц мониторе

**Включаем:** FG + апскейл (Quality/Balanced).

**Результат:**
- Иллюзия выше 60, часто стабильное ощущение ~90–120+ (при AVG 60–70 от рендера)
- Реальный input lag растёт на 1 кадр
- Для соревновательных режимов: FG выключить, оставить только апскейл для чёткости без доп. задержек

---

## Универсальные настройки под RX 9050

- **База (тени, текстуры, постпроцесс):** Medium/High, не Ultra — меньше нагрузка на VRAM и шину. Redstone дорисует детали
- **FG:** включать в PvE/single/coop, выключать в быстрых PvP (если важна отзывчивость)
- **RR:** всегда включать если игра поддерживает и используется RT — лучший баланс качества и производительности
- **Anti-Lag 2:** mandatory companion к FG — частично компенсирует задержку интерполяции

---

## Где RX 9050 + Redstone сильны

- 1080p при ограниченном бюджете и БП
- RT без покупки более дорогой карты (High/RT-On, не Path Trace Ultra)
- Низкая TBP (92W) + тихая система: FG позволяет не гнаться за чистым растром на ультра

## Где козырь не спасает

- Игра упирается в текстуры/геометрию при Ultra, 8GB/128-bit — Redstone поднимет чёткость и RT, но не отменит нехватку VRAM/пропускной способности
- Киберспорт с требованием минимального лага: FG лучше выкрутить, использовать только ML-апскейл + Anti-Lag 2
- Игры без поддержки DX12 / Agility SDK 1.4.9+ — стек недоступен
